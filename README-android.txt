نسخه اندروید دستیار فروش
=========================
روش ۱ (ساده‌ترین، بدون نصب چیزی): پوشه www را روی یک هاست HTTPS (مثلاً GitHub Pages / Netlify) آپلود کنید،
در کروم گوشی باز کنید → منو → «افزودن به صفحه اصلی / Install app». مثل یک برنامه نصب می‌شود و آفلاین کار می‌کند.

روش ۲ (APK): این پوشه را در یک مخزن GitHub بگذارید؛ Actions به‌طور خودکار app-debug.apk می‌سازد
(Artifacts → DastyarApp-apk). یا روی PC با Node و Android Studio:
    npm install ; npx cap add android ; npx cap sync android ; npx cap open android

داده‌ها داخل گوشی ذخیره می‌شوند. انتقال بین ویندوز و گوشی: تنظیمات ← «پشتیبان‌گیری» (دانلود JSON)
و «بازیابی» (انتخاب فایل JSON) — فایل dastyar_data.json نسخه ویندوز هم قابل بازیابی است.
در اندروید در دسترس نیست: تطبیق بارکد PDF/Excel، پنجره شناور، حالت ارائه. تغییر اندازه تصویر و خروجی (CSV برای اکسل) و چاپ کار می‌کنند.
